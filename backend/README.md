# Backend - Smart Loan Prediction

Flask backend skeleton for Smart Loan Prediction & Fraud Detection.

## How to run (dev)
1. Create virtualenv:
   python3 -m venv venv
   source venv/bin/activate
2. Install:
   pip install -r requirements.txt
3. Copy `.env.example` to `.env` and edit values.
4. Start:
   python app.py
